# Student Management System using Python

A simple console-based Student Management System developed using only Python.

## Features
- Add student
- View student records
- Search student
- Update student details
- Delete student
- Save records permanently in a JSON file

## Technologies
- Python
- JSON
- File Handling
- Functions
- Lists and Dictionaries

## How to Run

1. Install Python.
2. Open this project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python student_management.py
```

The `students.json` file will be created automatically when you add the first student.

## Interview Explanation

"I developed a Student Management System using Python. It is a menu-driven application that allows users to add, view, search, update, and delete student records. I used functions to divide the program into smaller parts, and I used lists and dictionaries to store student information. I used Python's built-in JSON module for file handling so that the records are saved even after the program is closed."
